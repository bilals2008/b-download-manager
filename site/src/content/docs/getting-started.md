---
title: Getting started
description: What B Download Manager does, and how to download your first file.
---

B Download Manager downloads files from the web and keeps them in one list. It fetches a file in several pieces at the same time, which is usually faster than a browser, and it can stop halfway and carry on later — even after you close the app.

## Open it

Start B Download Manager from the Start menu or from the shortcut on your desktop.

If nothing seems to happen, it may already be running. Look next to the clock in the bottom-right corner of the screen and click its icon.

The window has your downloads in the middle and a column of folders down the left: All downloads, Unfinished, Finished, and the kinds of file it sorts them into.

## Download your first file

1. Copy the link to the file: right-click the link on the web page and choose **Copy link address**.
2. In B Download Manager press <kbd>Ctrl</kbd>+<kbd>N</kbd>, or click the **+** button at the top. A small window asks for the address.
3. Press <kbd>Ctrl</kbd>+<kbd>V</kbd> to paste the link, then <kbd>Enter</kbd>.

The app checks the link before it starts, so the file's real name and size appear instead of whatever the link claimed. If the link has expired or needs you to sign in, it says so straight away rather than failing ten minutes later.

The file is saved in your Downloads folder. To put it somewhere else, change the folder in that same small window before you press Enter.

## While it downloads

- **Double-click** a download to see how it is doing, piece by piece.
- **Pause** stops it for now and keeps what it already has. **Resume** carries on from there.
- **Stop** ends it but leaves the entry in the list.
- A speed limit can slow everything down, so the rest of your work still has room.

You can close the window and it keeps downloading. When a file finishes, a small window offers to open it or to show it in its folder.
